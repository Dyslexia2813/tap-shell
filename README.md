# Tap-Shell

Android-обёртка (WebView) для https://tap.teamdream.online. Открывает только этот сайт.

- Полный экран: запускается без системных панелей, плавающая кнопка в углу переключает режим
  (выбор запоминается). Полноэкранное видео на сайте тоже работает.
- Вход по логину/паролю с 2FA: cookies сохраняются между запусками.
- Загрузка файлов на сайт и скачивание файлов (в папку «Загрузки»).
- Ссылки на другие сайты блокируются.
- Android 10 и новее.

## Сборка

Каждый push в `main` запускает GitHub Actions. APK лежит в Releases (тег `latest`)
и в Artifacts запуска.

Иконка берётся с сайта автоматически (манифест, apple-touch-icon, favicon).
Чтобы задать свою, положите `icon.png` (лучше 512×512) в корень репозитория.

Подпись: фиксированный ключ `app/debug.keystore`, поэтому новые сборки ставятся
поверх старых без удаления. Только для личного использования.
